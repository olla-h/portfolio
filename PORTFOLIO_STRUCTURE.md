# Recommended GitHub Structure

Use this portfolio as your GitHub profile README, then create separate repositories for the strongest technical projects.

Recommended repositories:

1. `eeg-motor-imagery-feature-selection`
2. `nlp-text-analytics`
3. `data-analytics-projects`
4. `pawperfit`
5. `e-livery`
6. `salimeen`

For each technical repository, include:
- README.md
- src/
- notebooks/
- figures/
- results/
- requirements.txt
- .gitignore

Do not upload confidential client information, private datasets, credentials, or proprietary source code.
