# NLP & Text Analytics

## Overview

A collection of natural language processing experiments covering preprocessing, summarization, keyword extraction, semantic representations, and transformer-based approaches.

## Work Included

- Text cleaning and preprocessing
- Tokenization
- Extractive summarization
- Keyword extraction
- Semantic sentence representations
- Transformer-based text representations
- Dataset preparation and troubleshooting

## Tools

- Python
- NLTK
- spaCy
- Sumy
- YAKE
- Sentence Transformers
- BERT
- Hugging Face
- scikit-learn
- pandas
- NumPy

## Example Workflow

Text → Cleaning → Tokenization → Feature/Embedding Representation → NLP Task → Evaluation

## Notes

The work included experimentation with public datasets such as CNN/DailyMail and XSum as well as Turkish-language datasets, including handling dataset encoding and tokenization challenges.
