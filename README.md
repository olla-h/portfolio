# Featured Work

## 🧠 EEG Motor Imagery & Feature Selection

A research project focused on EEG-based motor imagery classification and
interpretable feature selection.

The work investigated how spatial relationships between EEG channels and
frequency-band features could be incorporated into feature-selection methods.

### Methods

- Laplacian Score
- Joint Laplacian Score (JLS)
- Graph-based feature selection
- Spatial graph fusion
- SVM classification
- Feature-selection benchmarking
- Spatial and spectral priors

### Highlights

- Multi-band EEG feature representation
- EEG channel spatial graph construction
- Kronecker-product graph expansion
- Motor-area weighting
- Graph-based feature selection
- Comparison with RFE, Mutual Information, SelectKBest, F-test and other
  feature-selection methods
- Accuracy and selected-feature analysis
- Interpretation of selected EEG channels and frequency bands

→ [Project overview](projects/eeg-motor-imagery.md)

## 📝 NLP — Semantic Regulation Detection in Banking

A published research project applying Natural Language Processing and semantic
analysis to the detection of banking regulations.

### Publication

Dehkharghani, R., Hussein, O., Can, E., Oryngaliyeva, L., & Kantaş, H. (2025).
**"A Semantic Approach to Regulation Detection in Banking Domain."**
*Kamu Yönetimi ve Teknoloji Dergisi*, 7(2), 192–208.

**Role:** Co-author / NLP Research Contributor

### Work

- Natural language preprocessing
- Turkish-language text processing
- Keyword extraction using YAKE
- Semantic text representation
- Sentence-transformer-based analysis
- BERT-based language representation
- Semantic similarity
- Regulation detection
- Dataset preparation and processing
- Evaluation and analysis of results
- Research documentation and publication

### Technologies

`Python` `BERT` `Sentence Transformers` `YAKE`
`NLP` `Semantic Analysis`

### Results

The proposed approach achieved:

- **86% Precision**
- **89% Recall**

for the regulation detection task.

The system was designed as a semi-automated approach in which detected
regulations could be reviewed and validated by an expert.

→ [Project overview](projects/nlp-text-analytics.md)

→ [Published paper](https://dergipark.org.tr/en/pub/kaytek/article/1763869)
